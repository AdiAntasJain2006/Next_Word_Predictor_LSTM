# 🔤 Next Word Predictor using LSTM

A deep learning project that predicts the next word in a sequence using a **Long Short-Term Memory (LSTM)** neural network.

The project demonstrates the complete pipeline of building a basic next-word prediction system using TensorFlow/Keras, starting from text preprocessing and sequence generation to model training and next-word prediction.

---

## 🚀 Project Overview

The model learns patterns from a text corpus and predicts the most probable next word given a sequence of previous words.
